# Roteiro Prático — Sistema Nervoso
PWA estático para GitHub Pages.

## Publicação
Envie todo o conteúdo desta pasta para a raiz de um repositório GitHub. Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/root`.

## Recursos
Atlas com as imagens fornecidas, roteiro prático, checklists, anotações persistentes, fotografias armazenadas em IndexedDB, progresso, modo offline e instalação PWA.

## PDF
Use o botão “Gerar roteiro / Salvar como PDF”, que abre a impressão do navegador. Escolha “Salvar como PDF”. O CSS de impressão preserva a proporção das imagens e evita cortes.

## Versão completa atualizada
- Mantém as funções do aplicativo original.
- Acrescenta cone medular, cauda equina e filamento terminal.
- Acrescenta função fácil, caso cotidiano e áudio às estruturas didáticas principais, incluindo o percurso do tálamo aos nervos cranianos.
- Antes de imprimir/salvar em PDF, todas as caixas de anotações são expandidas pelo `scrollHeight`, evitando truncamento do texto digitado.
- Fotografias e imagens usam `object-fit: contain` na impressão para preservar a imagem inteira.

### Imagens do Atlas
O pacote original referenciava 12 JPGs, mas esses 12 arquivos de imagem não vieram anexados junto aos arquivos HTML/CSS/JS. Para que o ZIP não tenha links quebrados, esta entrega inclui como material visual disponível a imagem enviada e páginas renderizadas do roteiro PDF; os slots restantes estão identificados para substituição pelas ilustrações originais quando disponíveis.

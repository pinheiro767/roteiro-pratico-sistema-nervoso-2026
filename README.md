# Roteiro Prático — Sistema Nervoso
PWA estático para GitHub Pages.

## Publicação
Envie todo o conteúdo desta pasta para a raiz de um repositório GitHub. Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/root`.

## Recursos
Atlas com as imagens fornecidas, roteiro prático, checklists, anotações persistentes, fotografias armazenadas em IndexedDB, progresso, modo offline e instalação PWA.

## PDF
Use o botão “Gerar roteiro / Salvar como PDF”, que abre a impressão do navegador. Escolha “Salvar como PDF”. O CSS de impressão preserva a proporção das imagens e evita cortes.
